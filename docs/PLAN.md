# NowStation 계획 (2026-11-16 ~ 11-22, 7일)

## 무엇을
시작 버튼만 누르면 탄 열차를 자동으로 찾아, 잠금화면에 **현재역·다음역**을 실제 운행 그대로 보여 주는 앱.
경로 안내는 하지 않는다(사람들은 이미 알거나 지도 앱으로 확인한다).

| 넣는 것 | 빼는 것(이유) |
|---|---|
| 시작 버튼(출발역은 위치로 추천, 직접 고르기 가능) | 경로·환승 경로 안내(지도 앱이 함) |
| 탄 열차 자동 찾기(놓친 열차는 무시) | 회원가입(기기마다 익명 ID) |
| 현재역·다음역·정차 중(지연·임시 정차 그대로) | iOS(유료 개발자 계정 없음 → 다음) |
| 환승 자동 감지 | 전 노선(우선 2호선·수인분당선·신분당선) |
| (선택) 내릴 역 한 정거장 전 진동 | |
| 잠금화면 진행 중 알림(Android) | |

## 동작
```
[Android]                                  [서버]                          [서울시 실시간 API]
시작 → 출발역 보내기 ───────────────────→  탑승 세션
움직임 감지(출발/정차) 보내기 ──────────→  그 역을 떠난 열차와 시각 비교 ←── 탑승 중인 노선만 주기적으로
                                            → 탄 열차 확정·추적                (하루 1,000건 관리)
진행 중 알림 갱신 ←───── 받아 오기 ──────── 현재역·다음역
```
- 열차를 놓치면: 그 열차가 떠날 때 폰이 안 움직였으므로 따라가지 않는다.
- 임시 정차: API에서 열차가 그 역에 계속 있으므로 "정차 중"을 그대로 보여 준다.
- 환승: 내 열차는 떠났는데 폰이 안 움직임 → 내림. 그 역에서 다음에 폰과 같이 출발한 열차(노선 무관)를 따라간다.

## 실기기 없이 테스트
| 입력 | 실제 | 테스트 |
|---|---|---|
| 열차 위치 | 실시간 API | 출퇴근 시간 실제 응답을 녹화해 재생 |
| 폰 움직임 | 가속도 센서 | 에뮬레이터 센서에 스크립트로 값 주입(`adb emu sensor set acceleration`) |

시나리오: 정상 / 열차 놓침 / 임시 정차 / 환승 / 데이터 끊김 / 하차 알림.
한계: 실제 지하철 흔들림은 재현하지 못한다 → 움직임 판단 기준값을 한곳에 모으고 README에 "실기기 검증 필요"로 적는다.
